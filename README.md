# ResiSync
Smart living, connected communities — ResiSync brings residential operations into one intelligent platform.
ResiSync — IoT-Enabled Residential Operations Platform 🏠📡

A smart residential society management platform that connects residents, security guards, administrators, and IoT-enabled infrastructure in one unified ecosystem. ResiSync simplifies visitor management, maintenance payments, amenity bookings, helpdesk requests, emergency alerts, and real-time society monitoring through a modern, intuitive interface.

Key Features:

🏠 Resident & Society Management
👥 Visitor & Delivery Management
💳 Maintenance & Payment Tracking
🏊 Amenity Booking
🛠️ Helpdesk & Complaint Management
🚨 Emergency Alerts & Notifications
📡 IoT-Based Society Monitoring
👮 Security Guard Dashboard
📊 Admin Analytics Dashboard
🔐 Role-Based Access & Secure Authentication

Tech Stack: React Native • JavaScript/TypeScript • Firebase • IoT Integration • REST APIs
